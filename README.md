## Moin, ich bin Christopher 👋

Hier auf GitHub teile ich meine Hobbyprojekte unter **BxD / BabeinlovexD**. Ich verbinde Hardware und Software: von eigenen ESPHome-Komponenten über Smart-Home-Geräte und DIY-Audio bis zu Werkzeugen für kreative Ideen.

Ich tüftle, lerne dazu und entwickle meine Projekte Schritt für Schritt weiter. Wenn daraus etwas entsteht, das auch anderen hilft oder Lust aufs Nachbauen macht, freue ich mich umso mehr.

## Zusammen macht Tüfteln mehr Spaß

Du hast etwas nachgebaut, einen Fehler gefunden oder eine Idee für eine Erweiterung? Ich freue mich über Feedback, Erfahrungen mit anderer Hardware und Beiträge zum Code oder zur Dokumentation.

- **Fragen & Fehler:** Bitte ein Issue im passenden Repository öffnen – am besten mit Hardware, Version und einer kurzen Beschreibung.
- **Verbesserungen:** Vorschläge und Pull Requests sind willkommen. Größere Änderungen besprechen wir am besten vorher im zugehörigen Projekt.
- **Nachbauen & Anpassen:** Hinweise zum Aufbau, Entwicklungsstand und zur jeweiligen Lizenz findest du im Projekt-Repository.

Das hier ist ein Hobby: Die Projekte wachsen mit meinen Ideen und meiner Freizeit.
